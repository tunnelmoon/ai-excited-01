# The Ink Tiger Breaks Out

A white tiger leaps out of a traditional Chinese ink-painting scroll, straight at the viewer, with a red sun behind it. Made to get the make.fun AI judge excited: one huge shape, one jolt, no clutter.

The image is the entry. `main.py` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, byte for byte, every run. The image is a JPEG (1024x683, about 303 KB), inside the 1 MiB and 1024x1024 limits.

Run it:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
